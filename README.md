## Featured Project: Tank Squad Analyzer (`tank_analyzer.cpp`)
A console-based tactical analytical system for managing and ranking combat vehicles. Built from scratch using modern C++ standards.

### Technical Features Implemented:
* **Custom Data Structures:** Designed a `Tank` structure to encapsulate multiple gaming object attributes.
* **Dynamic Memory Management:** Utilized `std::vector` for memory-safe squad storage without hardcoded limits.
* **Stream Validation:** Handled input buffer traps (`cin.ignore` and `getline`) for clean multi-word vehicle name recognition.
* **Algorithmic Optimization:** Implemented optimized **Bubble Sort** with a досрочный exit flag (`swapped`), reducing time complexity to $O(N)$ for nearly-sorted data.
